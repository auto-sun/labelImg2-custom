# LabelImg2 Custom v2.3.3

这是一个大型数据集体验与标签安全性小版本，包含 `v2.3.2` 的全部功能。

## 新增：项目类别文件管理

- 可从 `File > 选择类别文件...` 或右侧 `Box Labels` 按钮选择任意 `class.txt`。
- 选择前预览类别 ID、名称与总数，自动记录最近 12 个文件并在重启后恢复。
- 切换类别文件不会修改当前图片已有框；失效的类别快捷键会安全移除。

## 修复：大型 labels 目录卡死

- 文件列表先立即显示，XML/TXT 数量和格式改为事件循环分批读取。
- 状态栏显示读取进度，扫描期间仍可切图、画框和使用菜单。
- labels 文件夹选择器只显示目录，不再读取同目录中上万个标签文件的信息。
- 使用 13,188 张图片和 13,188 个 TXT 标签的真实数据集验证：选择 labels 后约 0.32 秒返回，完整统计约 9.23 秒，界面保持响应。

## 修复：混合标签格式双文件

- 同名 XML/TXT 并存时读取修改时间较新的版本。
- 新标签保存成功后清理同名旧格式文件，避免两份标签继续分叉。
- 格式转换及模型覆盖/追加标注统一执行安全清理；无法识别的 TXT 保留并提示。

## 验证

- 完整自动化测试：86 项全部通过。
- Conda 启动环境、Python 语法和 Git 差异检查通过。
- 修复 Windows 下 `setup.py` 使用系统 GBK 读取 UTF-8 说明文件导致的打包失败。
- 真实大型数据集测试全程只读，未修改图片或标签。

## 升级说明

关闭旧版 LabelImg2 后，用 `v2.3.3` 文件覆盖旧程序目录并重新启动即可。图片和标签数据不需要转换。
