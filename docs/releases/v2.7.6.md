# LabelImg2 Custom v2.7.6

打开图片文件夹后，LabelImg2 会在它的上一级目录中查找 `labels` 或 `label`。检测到时可直接点击对应的目录，也可以选择其他文件夹。没有检测到时会打开系统的标签目录选择器。

没有上次工作可恢复时，主工作区显示欢迎页。可以从这里打开图片目录、打开图片、查看使用指南，也可以重新打开最近使用的项目或图片。

[下载 Windows 64 位安装包](https://github.com/auto-sun/labelImg2-custom/releases/download/v2.7.6/LabelImg2Custom-2.7.6-Setup.exe)
