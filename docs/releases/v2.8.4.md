# v2.8.4：批量处理图片、窗口收起动画与新功能导览

- **框选后批量处理。** 在文件列表右键批量标记待确认、取消标记或移入回收站。回收前会确认数量；共用标签、类别预设和智能体占用的图片会保留。
- **窗口收起不打断任务。** 智能体窗口可缩回入口并继续标注。类别、快捷键等应用窗口关闭时缩回打开位置；可在「设置」关闭动画。
- **升级后看新功能。** 第一次打开新版时会展示不会修改数据的示例。可跳过，在「帮助 → 新功能导览」重看，或关闭自动导览。
- **包含 v2.8.3 的人机分工。** 智能体可自己筛选图片，也可领取手动框选的一批。任务在独立窗口实时预览，主窗口仍能标注其他图片。

## 下载与更新

[Windows 64 位安装包](https://github.com/auto-sun/labelImg2-custom/releases/download/v2.8.4/LabelImg2Custom-2.8.4-Setup.exe)

已安装的用户可通过「帮助 → 检查更新」升级。安装器沿用原有安装目录，设置和标注文件仍保留。
