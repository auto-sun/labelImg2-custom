# LabelImg2 Custom v2.7.3

## 本次更新

- 多框 Ctrl 拖动复制：选中几个框就复制几个，整组保持尺寸、类别和相对位置；可用 Ctrl+Z 一次撤销。
- 四方向键微调增大为每次 5 个图片像素，贴边时仍限制在图内。
- 修复 Alt 拖动留白失效，BAT 与安装版均可在图片上下边缘继续拖出约三分之一可视画布的空白；保留流畅屏幕坐标平移。
- 文件菜单新增“重启软件”，处理未保存标注并保留项目设置，兼容源码和 EXE。
- 取消重复的 T 默认隐藏功能，保留 R（选中框/全部框）和 N（普通框）；T 可自定义类别。
- 修复 G 的自定义映射阻挡中文拼音轮选：编辑类别时第一次按 G 优先绑定类别，连续按 G 继续轮选果腐病、干枯症等同首字母类别；类别名称和空格保留。
- 修复角点悬停重绘闪烁，更新七种界面语言的菜单和指南。

## 下载与安装

[Windows 64 位安装包](https://github.com/auto-sun/labelImg2-custom/releases/download/v2.7.3/LabelImg2Custom-2.7.3-Setup.exe)

关闭旧版后运行安装器，可以安装到原目录覆盖升级；保留用户设置、类别历史及数据集。安装包包含运行与 CPU 推理依赖，不包含个人 `.pt` 模型或个人类别文件。

已有安装版可通过“帮助 → 检查更新”下载并升级。源码/BAT 用户请使用本版源码；检查更新会打开发行页面。
