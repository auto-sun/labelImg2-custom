# v2.8.5：双屏任务窗口与安装修复

- **双屏恢复。** 智能体任务窗口跑到屏幕外时，点击状态栏入口会把它拉回可见屏幕。调整窗口不会重置任务或丢失正在显示的预览框。
- **跨屏动画。** 收起窗口时以同屏淡出代替跨屏缩放，避免穿过不同缩放比例的屏幕之间的不可见区域。
- **覆盖安装。** 安装器会先正常关闭同一安装目录的主程序，再清理残留的 MCP 桥接。保存流程未结束或桥接被重新拉起时，会先提示，不替换程序文件。
