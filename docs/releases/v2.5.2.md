# LabelImg2 Custom v2.5.2

此版本修复 v2.5.1 Windows 安装包启动时出现的 `No module named 'pkg_resources.extern'` 错误。已下载或安装 v2.5.1 的用户请升级到本版。

- 安装包从单一、隔离的 Python 环境构建；打包流程会检查依赖来源，并实际启动 EXE 验证主窗口，报错弹窗不再被误判为启动成功。
- 升级时会更新已有的桌面快捷方式及图标；未创建过桌面快捷方式的用户仍可在安装时自行选择。
- 保留 v2.5.1 的高 DPI / 窄窗口布局、放大的设置窗口及 Windows 原生文件选择窗口。

下载 `LabelImg2Custom-2.5.2-Setup.exe`，关闭旧版后安装即可。无需 Conda 环境，个人设置和数据集不会被删除。

安装包 SHA-256：`28D761226CF6988B519A511889FC03786CA851FB9515F307E68F54AB0F3D977D`。

安装包未签名，Windows 可能显示“未知发布者”。仅从本仓库的 Release 页面下载。当前组合发行版按 GNU AGPL v3.0 开源，上游 LabelImg2 的 MIT 许可及署名继续保留。
