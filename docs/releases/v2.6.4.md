# LabelImg2 Custom v2.6.4

本次小版本修复贴边框角点在切换图片后首次拖动无响应的问题，增加单框
`Ctrl+V` 替换和右侧快捷键设置入口，并补齐七种界面语言的入口文案。

## 更新内容

- 切换图片时清除旧图角点悬停状态；按下鼠标时即时重新检测角点，因此不必先移动框即可调整贴边角和远角。
- 复制一个框后，选中另一个框并按 `Ctrl+V`，会以复制框替换目标框，同时保留目标框的位置。使用 `Ctrl+Z` 可撤销；选中复制源时仍会正常粘贴新框。
- 右侧 `Box Labels` 增加“标签快捷键设置”入口；英文、简体中文、日文、西班牙文、阿拉伯文、法文和韩文界面均会显示对应语言。

## 安装

下载 `LabelImg2Custom-2.6.4-Setup.exe`，关闭已经运行的 LabelImg2 Custom 后安装。
已有数据集和个人设置不会被删除。安装包包含运行依赖，但不包含模型 `.pt` 权重。
安装包未签名，Windows 可能显示“未知发布者”；请只从本项目 GitHub Release 下载。
