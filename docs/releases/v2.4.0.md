# LabelImg2 Custom v2.4.0

本版包含 v2.3.3 的全部功能，重点改进大型项目中连续查看、标记和管理图片的操作。

## 主要更新

- 中文类别支持拼音查找；双击已有框的类别后，也可按已设置的类别快捷键直接改类。画布和快捷键控件在中文输入法开启时仍能接收操作按键。
- File List 可将暂时无法确定类别的图片标记为淡红色“待确认”，刷新或重启后保留。右键菜单在鼠标位置弹出，不再因图片自动居中而偏移。
- File List 增加刷新按钮和 `F5`，重新读取图片及标签目录；标签数量继续在后台分批扫描。
- File List 支持右键或 `Del` 删除图片及对应 XML/TXT，文件进入系统回收站；右键删除需确认，`Del` 直接执行。
- 图片切换使用 `↑ / ↓`，选中框时四个方向键用于逐像素微调。连续切图时当前行保持居中，右键操作时不移动。
- 普通框和 OBB 的角点及命中范围加大，更容易拖动调整。

## 验证与升级

- 自动化测试 117 项全部通过，包括长图片列表右键定位和键盘切图居中测试。
- 升级前保存当前标注并完全退出旧版程序；若开启了多个 LabelImg2 窗口，请全部关闭后再启动新版。
- 图片和现有 XML/TXT 标签不需要转换。
