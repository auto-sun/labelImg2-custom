# LabelImg2 Custom v2.3.2

这是一个稳定性补丁版本，包含 `v2.3.1` 的全部功能，并修复文件列表和类别输入工作流中的三个问题。

## 本次修复

- 模型标注或格式转换刷新 File List 时，按照图片完整路径保留已有的绿色确认状态。
- 文件列表改用确定性自然排序：数字段按整数值，字母段忽略大小写按字母顺序。
- 修复带前导零或长编号的文件名错序，例如 `000102` 现在会正确排在 `000200` 前。
- 类别下拉框处于首字母选择状态时临时禁用 `E` 画 OBB 快捷键，输入 `e` 只匹配类别。
- 退出类别编辑后自动恢复 `E` 快捷键原来的启用状态。

## 验证

- 完整自动化测试：69 项全部通过。
- 覆盖数字前缀、字母大小写、递归子目录和类别输入真实按键事件。
- Python 差异检查通过。
- 仓库预设类别文件未修改。

## 升级说明

关闭旧版 LabelImg2 后，用 `v2.3.2` 文件覆盖旧程序目录并重新启动即可。图片和标签数据不需要转换。
