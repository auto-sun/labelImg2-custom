# LabelImg2 Custom v2.5.3

此版本修复 `Ctrl+Shift+L` 显示框标签文字无效的问题。

- 开启“Paint Labels”后，框上显示类别名；如果填写了 Extra Info，也会一起显示。
- 再按一次 `Ctrl+Shift+L` 可隐藏文字，切换后立即刷新画布；修改类别时显示的名称也立即更新。
- 靠近图片顶边的框，标签文字不会因基线位于画布之外而被截掉。
- 保留 v2.5.2 的安装包启动修复、桌面快捷方式更新及界面适配功能。

下载 `LabelImg2Custom-2.5.3-Setup.exe`，关闭旧版后直接安装即可。无需 Conda 环境，不会删除数据集或个人设置。

安装包 SHA-256：`F61C7F2C4290D570F2BA393E85365AF4DDAB8BD0C3E37C7FAF1FA9DA957E9B6C`。
