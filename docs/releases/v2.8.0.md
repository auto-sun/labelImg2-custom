# v2.8.0：智能体连续标注与按类管理

**[下载 Windows 64 位安装包](https://github.com/auto-sun/labelImg2-custom/releases/download/v2.8.0/LabelImg2Custom-2.8.0-Setup.exe)**，无需另装 Python。SHA-256：`09b98e1993f34da93cc2195a3139746e1b0bef814b26e724f60853f236ea7469`。

- **连续标注：** 在设置中复制 MCP 配置并授权当前项目。兼容 stdio 和图片工具结果的智能体可从当前图开始，按指定张数或直到末尾逐张提交，无需在 LabelImg2 中逐张确认。图像可能被发送给所选智能体的模型服务商，请只授权允许共享的数据。
- **保护已有工作：** 跳过已存在的 XML/TXT，包括空标签；不确定的图片可标红、不写空文件。可以停止任务并续做，过期提交不会覆盖新标签。
- **框标签分组：** 每类可折叠、整组显隐、全选或批量改为另一预设类别，支持一次撤销批量改类。
- **文件列表与项目打开：** 修复滚动与高亮不同步；包含空工作区欢迎页、同级标签目录检测。
