# LabelImg2 Custom v2.6.0

This release improves box-boundary behavior, adds per-box visibility controls,
and reorganizes settings and help.

## What's new

- Moving rectangle, OBB, or multi-selected boxes is constrained to the image.
- Start drawing outside the image; completed boxes snap to the image boundary.
- Start marquee selection in blank canvas space outside the image.
- Press `R` to hide/show selected boxes, or all boxes with no selection.
- Press `Ctrl+Shift+L` to hide/show selected box labels, or all labels with no selection.
- `Help > User Guide` explains shortcuts first, then basic and advanced workflows.
- `Settings` now contains annotation format, label shortcuts, language, autosave,
  box-label display, and corner-display options.
- Choose English, Simplified Chinese, Japanese, Spanish, Arabic (RTL), French,
  or Korean; the selection persists between launches.
- Open Dir and Open Annotation Dir now have distinct icons.

## Install

Download `LabelImg2Custom-2.6.0-Setup.exe`, close any running LabelImg2 Custom
window, and install the update. Existing datasets and application preferences
are not removed.
