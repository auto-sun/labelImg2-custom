# LabelImg2 Custom v2.3.1

这是一个补丁版本，在 `v2.3.0` 全部功能的基础上增加模型自动标注置信度调节。

## 本次更新

- 上方工具栏新增置信度数值框，范围 `0.01–1.00`，默认 `0.25`，步长 `0.05`。
- “自动标注”和“标注当前图”共用当前置信度，并直接传给 Ultralytics 的 `conf` 参数。
- 置信度会保存到本机设置，下次启动自动恢复；无效的旧设置会安全回退到 `0.25`。
- 模型推理期间锁定置信度控件，防止同一批任务中参数被意外修改。
- 状态栏、工具提示和完成窗口会显示本次实际使用的置信度。
