# LabelImg2 Custom v2.6.1

This patch release improves multilingual help text and marquee selection.

## What's fixed

- Toolbar hover explanations are translated in all seven UI languages. Technical names such as YOLO, OBB, File List, XML/TXT, and `.pt` remain in English where appropriate.
- The confidence control prefix and explanation follow the selected language; confidence values in model-loading and result messages are localized too.
- Marquee selection now uses the full canvas coordinate range. It no longer snaps to image edges and can be dragged from outside one image edge to outside the opposite edge.

## Install

Download `LabelImg2Custom-2.6.1-Setup.exe`, close any running LabelImg2 Custom
window, and install the update. Existing datasets and application preferences
are not removed.
