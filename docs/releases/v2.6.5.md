# LabelImg2 Custom v2.6.5

发布日期：2026-09-27

本次修复旧标签载入后，部分贴边框仍需先整体移动才能拖动角点的问题。
v2.6.4 处理了切换图片后的角点悬停与命中状态；本次补充处理标签几何本身
因保存精度或历史越界而不符合图片边界限制的情况。

## 问题原因

旧版 XML 保存时将框中心、宽高舍入至 4 位小数，将角度舍入至 6 位小数。
例如精确的 `π` 会写成 `3.141593`，重新读入后原本贴边的角点可能出现微小越界。
一些历史标签本身也已超出图片边界。原来的拖角逻辑要求初始矩形完全在图内，
因此会拒绝这些框的首次拖角；整体平移将框带回图内后，拖角才恢复。

## 更新内容

- 禁止越界时，首次拖角编辑先将已有越界矩形整体平移回图内，再进行角点调整；
  如果框大到无法完整放入图片，则先等比缩小，保持 OBB 的矩形形状。
- 相邻角点改用正交投影计算，避免接近水平或垂直时的斜率计算不稳定；
  位于旧 XML 角度量化误差范围内的近轴向框恢复精确水平或垂直方向。
  正常有效框调整时仍固定对角点。
- 修复角点仅略微越过图片底边时误吸附到顶边的问题，现在吸附到正确的底边。
- 后续 XML 保存保留浮点精度，不再将中心、尺寸和角度固定舍入到 4/6 位小数。
- 安装包只包含公开默认类别，不再将本地 `data` 目录里的个人类别文件一起打包。
- 增加旧 XML 往返读写、无悬停首次拖角、四边四角、斜框、历史越界框、
  超大框等比修复、固定对角和保存精度的回归测试。

## 对现有标签的影响

打开或切换图片不会批量修正或重写已有标签，也不需要批量转换整个数据集。
边界修复只在对应框的拖角编辑中进行；修改按原有手动保存或自动保存流程写回。
已有越界框可能在首次拖角时整体移动，超大框可能等比缩小，这是将框恢复到图内的
必要调整。v2.6.4 的单框 `Ctrl+V` 替换、撤销和右侧标签快捷键设置入口继续保留。

## 安装

下载 [LabelImg2Custom-2.6.5-Setup.exe](https://github.com/auto-sun/labelImg2-custom/releases/download/v2.6.5/LabelImg2Custom-2.6.5-Setup.exe)，
关闭已经运行的 LabelImg2 Custom 后安装。
已有数据集和个人设置不会被删除。安装包包含运行依赖，但不包含模型 `.pt` 权重。
安装包未签名，Windows 可能显示“未知发布者”；请只从本项目 GitHub Release 下载。
