# v2.8.8：快捷改类、任务计时与画布留白

- **双击快捷改类。** 双击画布上的框可改类；多选时双击其中一个框会修改全部选中框，双击右侧类别组标题会修改整组（包括隐藏框）。用首字母、拼音或自定义类别快捷键选择，Enter 应用，Ctrl+Z 可撤销整批。
- **任务耗时。** 智能体任务窗口显示总耗时和平均每张耗时，暂停或停止后保留已累计的时间，续做继续累计；跳过的图片不计入平均张数。
- **确认状态更清楚。** 用 Ctrl+Shift+M 切换当前图片的待确认标记。空格确认后的绿色优先显示，标记仍保留；普通保存不会掩盖待确认的淡红色。
- **滚轮缩放和默认留白。** 未选中框时，滚轮和 Ctrl+滚轮每格放大或缩小图片 4 个百分点；打开或切换图片时默认四边至少留白 20 px。已选中框的缩放灵敏度和 Alt 拖动不变。

可从旧版的「帮助 → 检查更新」升级，也可直接下载 Windows 64 位安装包覆盖安装。不需要卸载旧版或另装 Python。
