# v2.8.2：更新提醒显示主要改动，MCP 支持实时打框

- **先看改动，再决定是否升级。** 启动时自动检查和「帮助 → 检查更新」都会显示新版最多五条主要改动，也可展开查看完整发行说明。此功能从 v2.8.2 客户端生效；旧版升级到本版时仍使用旧弹窗。
- **实时查看智能体正在标的框。** 智能体调用 `preview_box` 后，画布立即显示带编号和类别的虚线候选框，可用同一编号修正。预览不写入文件，整张图最终提交时才会保存。升级后请重连 MCP 客户端并刷新工具列表。
