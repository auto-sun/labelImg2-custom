# LabelImg2 Custom v2.5.1

这是 v2.5.0 安装版的界面适配更新，保留此前全部标注与自动标注功能。

- 工具栏按控件文字和屏幕宽度调整，高 DPI 或较窄窗口下自动分行，避免“置信度”“框型”和缩放比例被截断。
- 标签快捷键设置及类别文件管理窗口随屏幕可用空间调整，表格行不再挤压输入控件。
- 打开图片目录、标签目录及选择 `class.txt` 时使用 Windows 原生文件选择窗口。

下载 `LabelImg2Custom-2.5.1-Setup.exe`，关闭旧版程序后运行安装器即可升级。安装包包含运行依赖，不需要 Conda 环境；已有数据集和个人设置不会被删除。
