# LabelImg2 Custom v2.6.3

This patch release fixes edge-attached box corners that could not be resized
when the box used a horizontal or vertical orientation.

## What's fixed

- Horizontal and vertical boxes now use stable coordinate projections when
  calculating adjacent corners, avoiding tiny floating-point overshoots at
  image boundaries.
- All four corners of edge-attached boxes remain resizable and the resulting
  points stay inside the image.

## Install

Download `LabelImg2Custom-2.6.3-Setup.exe`, close any running LabelImg2 Custom
window, and install the update. Existing datasets and application preferences
are not removed.
