# v2.8.7：框标签布局与双屏显示修复

- **框标签更易读。** 类别列会利用侧栏剩余空间，打开图片、切图或撤销时不再被挤回默认窄列。颜色用小色标表示，保留分类折叠、批量选择、隐藏和改类。
- **文件列表滚动显示同步。** 滚轮、滚动条和切图都会重绘可视列表，避免旧文件名留在屏幕上、点击却选中另一张图。
- **双屏任务窗口尺寸恢复。** 在不同缩放比例的屏幕之间切换后，如果窗口被压成横条，会恢复到最近的正常尺寸。正常跨屏拖动不受影响，标注进度和实时预览会保留。

可从旧版的「帮助 → 检查更新」升级，或下载下方 Windows 64 位安装包覆盖安装。不需要卸载旧版，也不需要另装 Python。
