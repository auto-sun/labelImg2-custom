# LabelImg2 Custom v2.5.0

这是首个可直接安装的 64 位 Windows 版本。下载下方的 `LabelImg2Custom-2.5.0-Setup.exe`，双击安装后从开始菜单启动，无需配置 Python、Conda 或其他运行依赖。

本版还加入工具栏“普通框 / OBB”选择：按 `E` 会根据当前选择画框，再按一次退出；原有两个画框按钮仍保留。安装版会把个人设置写入用户 AppData，不会尝试写入程序安装目录。

安装包包含 CPU 版自动标注运行依赖，但不附带模型 `.pt` 权重。安装包尚未签名，Windows 可能提示“未知发布者”。建议只从本仓库的 Release 页面下载。

安装包 SHA-256：`C995A8330BEA9B3A4B6576D397044A40D3CBB66C3F4628E00E800AD34A2342C3`

旧的 GitHub Releases 已下架；历史代码和更新记录仍保留。完整说明见 [中文主页](https://github.com/auto-sun/labelImg2-custom/blob/v2.5.0/README.md) 和 [首次使用教程](https://github.com/auto-sun/labelImg2-custom/blob/v2.5.0/FIRST_USE_GUIDE_zh-CN.md)。
