# LabelImg2 Custom v2.3.0

`v2.3.0` 集中发布 `v2.2.0` 之后的标注效率、格式管理和统计改进。

## 主要新增

- 上方工具栏新增“生成空标签”，按当前格式为当前图片生成空 XML 或 TXT；已有框时先确认，保存失败自动恢复，并支持 `Ctrl+Z`。
- `Box Labels` 新增自定义标签快捷键，可配置多组“按键 → class.txt 预设类别”；自动拒绝重复键和现有功能冲突。
- 右侧新增标签统计，实时显示项目总标签数、当前图片标签数和本次工作新增标签净数量。
- 新增 `Ctrl+X` 多框剪切；剪切后的第一次粘贴保留原坐标，剪切和粘贴可分别撤销。

## 格式与保存

- 切换 `Annotation Format` 时可在 XML、YOLO 和 YOLO OBB 之间批量转换已有标签，并显示进度及中止按钮。
- 转换成功后才移除旧格式；失败或尚未处理的文件保留原内容。
- 移除重复的 `Export to`，统一使用双向格式转换流程。
- `View > Auto Saving` 首次启动默认开启，用户手动选择仍会跨重启保存。
- 当前图片单张模型标注的覆盖或追加结果可作为一步整体撤销。

## 兼容性与验证

- 保持现有 XML、YOLO、YOLO OBB 标签和本地设置兼容。
- 不包含任何模型权重；自动标注仍需使用自己训练或合法获得的 `.pt` 文件。
- 已通过 60 项自动化测试、Python 语法编译和 Conda 启动器检查。
- 当前整体发行版继续按 GNU AGPL v3.0 免费开源，上游 MIT 版权及许可证声明保持不变。
