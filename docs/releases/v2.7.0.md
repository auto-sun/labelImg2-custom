# LabelImg2 Custom v2.7.0

发布日期：2026-09-29

## 本次更新

- 连续 Del：删除后文件列表保留键盘焦点，可继续删除下一张图片；图片和对应标签进入回收站。
- 标签目录匹配：在 `a/b/img/c` 打开图片、选择 `a/b/labels` 标注后，再打开 `a/b/img` 能按记住的对应关系读取原标签。读取、统计、保存、自动标注和删除使用相同路径规则。
- 旧版没有目录对应记录时，兼容唯一文件名的扁平 XML/TXT 标签。同名图片有歧义时不自动套用扁平标签，需打开对应子目录并重新选择标签目录。
- 帮助菜单新增“检查更新”。启动时默认后台检查 GitHub 最新正式版本，发现新版后询问是否更新。取消“启动时自动检查更新”后，之后启动不再自动检查；仍可手动检查。
- 安装版同意更新后显示下载进度，可以取消。下载完成校验文件大小及 SHA256，按现有保存流程处理未保存标注，再运行安装器升级原目录。正在模型推理时不会强制退出。
- 源码 BAT 运行或新版未提供可校验的安装包时打开发行页下载。网络失败不会阻塞标注；启动检查失败不弹窗干扰。
- 更新功能界面支持英文、简体中文、日文、西班牙文、阿拉伯文、法文和韩文。

## 安装

[下载 Windows 64 位安装包](https://github.com/auto-sun/labelImg2-custom/releases/download/v2.7.0/LabelImg2Custom-2.7.0-Setup.exe)。
旧版尚无软件内更新功能，需要先下载安装本版本；以后的新版可以从帮助菜单检查。
安装包包含运行依赖，不包含 `.pt` 模型权重。个人数据集和类别文件不随安装包发布。
