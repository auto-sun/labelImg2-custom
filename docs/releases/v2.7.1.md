# LabelImg2 Custom v2.7.1

发布日期：2026-09-29

- 修复按住 `Alt + 鼠标左键` 平移画布时的卡顿、停顿和回弹。
- 原因是滚动条改变了画布局部坐标，下一次鼠标事件使用旧坐标时会抵消上一段位移；现在用稳定的屏幕坐标计算每次拖动增量。
- 优化拖动光标更新，重复设置相同光标不会触发额外重绘。
- 增加回归测试，覆盖不同缩放、连续拖动、静止指针、滚动边界反向拖动和释放时最后一段位移。

本次只修改平移交互，不会改变已有图片、标签或目录关联。你可以继续使用当前已安装的 v2.7.0，在“帮助 → 检查更新”中测试升级到本版本。

[下载 Windows 64 位安装包](https://github.com/auto-sun/labelImg2-custom/releases/download/v2.7.1/LabelImg2Custom-2.7.1-Setup.exe)。本次发布后不会自动替换你电脑上的现有安装版。
