# LabelImg2 Custom v2.7.5

## 本次更新

- 图片滚轮每格缩放改为 2 个百分点，选中框每格缩放约 2%，操作更细。
- 打开/切换图片默认居中适应窗口，四周至少留出 10px 空白；支持横图、竖图和不同窗口分辨率。
- 初始适应比例使用最终可视画布尺寸，考虑滚动条与工具栏布局变化，避免切图后仍贴边；手动缩放不会被强制复位。
- 文档补充现有 Ctrl+滚轮用法：未选中框时缩放图片，已选中框时仍优先调整框大小。此项只补充说明，不修改快捷键逻辑。
- 保留 v2.7.4 的 Alt 四向留白及此前全部功能，更新七种语言的使用指南。
