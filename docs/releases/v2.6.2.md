# LabelImg2 Custom v2.6.2

This patch release fixes resizing boxes whose corner handles are attached to an image edge.

## What's fixed

- Dragging an edge-attached corner no longer becomes unresponsive when the pointer crosses the image boundary; the pointer is clamped to the nearest image edge so the box can still be resized along that edge.
- Rotated boxes resize to the furthest valid position while keeping all corners inside the image.

## Install

Download `LabelImg2Custom-2.6.2-Setup.exe`, close any running LabelImg2 Custom
window, and install the update. Existing datasets and application preferences
are not removed.
