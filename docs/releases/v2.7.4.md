# LabelImg2 Custom v2.7.4

## 本次更新

- 补齐 Alt + 鼠标左键拖动的左右留白，四个方向均可越过图片边缘继续平移。
- 左右各允许约三分之一可视画布宽度，上下各允许约三分之一可视画布高度；不是原图尺寸的三分之一。
- 使用真实画布尺寸计算滚动范围，BAT/源码与安装版一致，缩放、切换图片和调整窗口后继续有效。
- 更新七种语言的使用指南和中文/英文文档；保留 v2.7.3 的多框 Ctrl 拖动复制、5 像素微调、重启软件和中文类别轮选等功能。

## 下载与安装

[Windows 64 位安装包](https://github.com/auto-sun/labelImg2-custom/releases/download/v2.7.4/LabelImg2Custom-2.7.4-Setup.exe)

先保存并关闭旧版，安装到原目录覆盖升级即可。也可通过“帮助 → 检查更新”升级安装版。源码/BAT 用户下载本版源码。

保留用户设置与数据集；安装包包含运行和 CPU 推理依赖，不包含个人类别或 `.pt` 模型。继续免费开源，整体采用 AGPL-3.0，保留上游 MIT 版权与许可声明。
